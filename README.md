


# ✈️ YatraPay

> Smart Group Travel Expense Management Platform

YatraPay is a modern web application designed to simplify group trip expense management. Whether you're traveling with friends, family, colleagues, or a tour group, YatraPay helps track shared expenses, split costs fairly, monitor balances, and settle payments efficiently.

## 🌟 Overview

Managing expenses during group trips can quickly become confusing:

* Who paid for what?
* How much does each person owe?
* Are all expenses settled?
* Who needs reimbursement?

YatraPay solves these problems through an intuitive and user-friendly platform that enables real-time expense tracking, automatic cost splitting, and transparent settlement management.
